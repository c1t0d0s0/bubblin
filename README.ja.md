# Bubblin' (バブリン) 🫧

[English (README.md)](./README.md)

『**Bubblin'**』は、名作アーケードゲーム『パズルボブル（Bust-A-Move）』の楽しさと爽快感をモダンなWeb技術（**Vite + TypeScript + HTML5 Canvas 2D + Web Audio API**）で再現・進化させたブラウザパズルゲームです。

PCでもスマートフォンでも快適に遊べるレスポンシブ設計で、立体的な3D光沢バブル、壁バウンドをシミュレートする弾道予測線、ヒットストップや花火を伴う大量落下の圧倒的な爽快感、Web Audio APIで合成された重厚なトランペット・ファンファーレ、そして段階的に手応えが増す全30ステージを搭載しています。

---

## 🌟 主な特徴

- **3D球体バブル描画**: 放射グラデーション、鏡面ハイライト、環境遮蔽シャドウによる光沢感あふれる立体表現。色覚多様性に配慮したシンボルマーク（ハート、滴、クローバー、星、ダイヤ、太陽）を内包。
- **反射予測弾道ガイド**: 発射台の角度に応じ、左右の壁反射（バウンド）と着弾予測サークルをリアルタイムで点線描画。
- **六角格子物理＆吸着**: 偶数行8列・奇数行7列の六角グリッド。微小サブステップによる壁すり抜け防止と、最近傍空きセルへの正確な吸着。
- **マッチ3＆連鎖破裂**: 幅優先探索（BFS）による同色クラスタ検出。3個以上連結で破裂し、コンボ数に応じて音階が上昇。
- **大量落下の圧倒的な爽快感演出**:
  - **ヒットストップ（瞬間静止）**: 4個以上のバブルを一気に切り離した瞬間に60〜120msの時間静止を発生させ、切断の重厚感を演出。
  - **切断衝撃波＆画面フラッシュ**: 切断の起点から光輪リングが拡散し、画面全体が発光＆強いカメラ振動。
  - **彗星のような光跡トレイル**: 落下中のバブル背後に色別の発光軌跡（コメットトレイル）を描画。
  - **床着地時の花火バースト**: 画面下に到達したバブルが弾けるポップ音とともに星形花火を散らし、追加スコア（+150）を連続獲得。
  - **特大アーケードバナー**: 落下数に応じて「GREAT」「EXCELLENT」「AMAZING」「LEGENDARY」の光る立体プレートバナーと紙吹雪が出現。
- **天井降下＆デッドライン**: ショットを外すごとにメーターが減少し、ゼロになると天井が1段下降。画面下のデッドラインを越えるとゲームオーバー。
- **外部アセット不要のプロシージャル音響**: Web Audio API によるリアルタイム減算合成：
  - ステージクリア時の**トランペット・ブラスアンサンブル・ファンファーレ**（微小デチューン鋸波＋レゾナントフィルター＋ビブラート）。
  - 重低音サブベース、アルペジオ報酬音、バブル着弾音、壁バウンド音。
- **全30ステージの滑らかな難易度曲線**:
  - **STAGE 1〜6 (初級)**: 3色限定、天井降下7〜8発、手詰まりしにくい開かれた陣形。
  - **STAGE 7〜14 (中級)**: 4色（Yellow/Purple解禁）。スウィートハート、王冠、インベーダーなどのモチーフ陣形。
  - **STAGE 15〜22 (上級)**: 5色（Orange解禁）。蝶、錨、神殿の柱など、根元を狙うパズル性と壁反射の技術が活きる陣形。
  - **STAGE 23〜30 (達人)**: 6色フルカラー。DNAヘリックス、ドラゴンアイ、ラストバトル。全制覇時は「ALL 30 STAGES CLEARED!」演出と周回ループモードへ。
- **PC＆スマホ両対応ハイブリッドUI**: マウス・キーボード操作に加え、スマホ向けの左右旋回レバースライダー、左右ボタン、大画面「LAUNCH」ボタン、画面スワイプ操作を完備。

| 操作 | PC (デスクトップ) | スマートフォン / タッチ端末 |

## 🚀 起動・開発手順

### 前提条件
- Node.js (v18以上推奨)
- npm (または pnpm / yarn)

### インストールと起動

```bash
# 1. リポジトリ内へ移動
cd bubblin

# 2. 依存関係のインストール
npm install

# 3. 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:5173/` にアクセスするとゲームをプレイできます。

### プロダクションビルド

```bash
# 型チェックとビルドの実行 (dist/ ディレクトリへ出力)
npm run build

# ビルド成果物のローカルプレビュー
npm run preview
```

`dist/` 配下のアセットは相対パス (`base: './'`) で生成されるため、サブディレクトリや GitHub Pages、静的ホスティングサーバーにそのままデプロイして動作させることが可能です。

## 🏗️ ファイル構成

```
bubblin/
├── index.html              # HTMLエントリーポイント、レスポンシブUI、モーダル
├── style.css               # アーケードネオンデザイン、タッチレバー、モバイル対応CSS
├── vite.config.ts          # Vite設定 (相対パス base: './')
├── tsconfig.json           # TypeScript厳格モード設定
├── package.json            # パッケージ情報・ビルドスクリプト
└── src/
    ├── main.ts             # メインループ、ヒットストップ、状態管理、イベント統合
    ├── types.ts            # データモデル・型定義
    ├── constants.ts        # グリッド寸法、カラーパレット、物理定数
    ├── grid.ts             # 六角グリッド幾何計算、吸着判定、デッドライン判定
    ├── matching.ts         # BFSマッチ3検出、天井連結BFSによる浮遊バブル判定
    ├── physics.ts          # 弾道レイキャスト、壁反射、重力落下、着地花火判定
    ├── renderer.ts         # 3D球体バブル描画、軌跡ガイド、彗星トレイル、バナー
    ├── audio.ts            # Web Audio API トランペットファンファーレ＆効果音合成
    ├── stages.ts           # 難易度ブラケット設計に基づく全30ステージデータ
    └── ui.ts               # HUD更新、タッチレバー操作、クリア・ゲームオーバー画面
```
